## 🎬 算法可视化怎么用

题目页下方的「算法可视化」区是**同一页面**内的逐步对照台：

1. 左边是**标准算法**，右边是**你写的算法**（默认是挖空模板，点「载入标准算法」可以对照着改）。
2. 两边都用同一套 API 编写，在同一组输入上运行：

```js
function solve(input, T) {
  var tk = T.tokens;                 // 按空白分词读取输入
  var n = tk.int(), a = tk.ints(n);

  var S = { a: a, i: 0, ans: 0 };    // S 就是"当前可见状态"，会被逐帧渲染
  T.step(S, '初始状态');              // 记录一步

  for (S.i = 0; S.i < n; S.i++) {
    S.ans += S.a[S.i];
    T.step(S, '累加 a[' + S.i + '] = ' + S.a[S.i]);   // 每步都调用 T.step
  }

  T.answer(String(S.ans));           // 声明最终答案
  return String(S.ans);
}
```

3. 点「▶ 运行并对比」：两边同步播放，**当前执行到的代码行会高亮**，第一处状态分歧自动标红。
4. 结论分四档：`完全一致` / `结论正确但过程不同` / `结论错误` / `运行失败`，并给出步数比（看你的写法是更优还是更绕）。
5. 点「🎲 随机对拍找错」，系统会造小数据暴力对拍，找到反例后一键载入逐步对比——这是考场查错最有效的手段。

> 可视化输入是小规模数据（保证 ≤200 步），评测用的是完整测试点。

### 本机推送前请先开加速器

本机 hosts 把 `github.com` 指向了 `127.0.0.1`，直连 GitHub 会失败；需要先启动
**Watt Toolkit（瓦特工具箱 / Steam++）** 并开启网络加速，它会代理 `github.com`。

```powershell
# 自动检测/启动 Watt Toolkit，等连通后推送（推荐）
powershell -ExecutionPolicy Bypass -File tools/push-to-github.ps1
```

脚本会：① 若 Watt Toolkit 没运行就自动拉起 `D:\steam++\Steam++.exe`；② 用 `git ls-remote`
轮询直到 GitHub 真正可达；③ 执行 `git push`。只想确认连通性可加 `-WaitOnly`。

> 改完静态资源记得同步提升 `index.html` 里的 `?v=` 版本号 —— 否则浏览器会继续用旧的
> CSS/JS（本项目的 `theme.css` 曾经因此没生效，导致星图动效完全不动）。

## ⚙️ 关于实时评测

GitHub Pages 只能托管静态页面，无法在后端编译 C++，因此本站通过浏览器调用
**Wandbox**（`https://wandbox.org/api/compile.json`，公共、免密钥、支持 CORS）编译并运行代码，
再用题目自带的隐藏测试数据判定。

- 编译环境：gcc 13.2.0（`-std=c++17`），支持 `#include <bits/stdc++.h>`。
- 判定规则与官方一致：**按通过测试点比例给分**，某个测试点通过即得分。
- 相同「代码 + 输入」的结果会缓存，避免重复请求；服务繁忙时会自动退避重试。
- 评测结果以官方评测环境为准，本站仅用于备考练习。

## ✅ 内容质量如何保证

题库不是「看着像对」就算对，每题都经过**多轮独立验证**：

1. **JS 追踪版 vs 期望输出**：`algo.ref`（可视化用的实现）在每组测试点上运行，输出必须与 `tests[i].output` 逐字节一致。
   → 当前 **75 题 × 5 测试点 = 375 组全部通过**。
2. **C++ 参考解 vs 期望输出**：`std.code` 提交到 Wandbox 真实编译运行，输出必须与期望一致。
   → 由 `tools/verify-cpp.js` 全量复核（编译服务限流时会自动退避重试，并把「服务繁忙」与「真正的编译/运行错误」区分开）。
3. **可视化逐步渲染**：`algo.viz` 声明的每个状态字段都必须在算法真实产生的步骤里存在，且每一步都能画出来。
   → `tools/verify-render.js`：**75 题每一步渲染均为非空结构**。
4. **浏览器端到端走查**：在真实浏览器里打开页面，检查控制台无报错、无 404，逐步播放、切换知识点卡片、筛选题库均正常。

```bash
node tools/verify.js          # 数据层校验（离线）
node tools/verify-render.js   # 可视化逐步渲染自检（离线）
node tools/verify-cpp.js      # C++ 参考解独立验证（需联网）
```
